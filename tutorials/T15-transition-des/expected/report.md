# Expected report structure

Begin with the engineering observable and missing-physics hypothesis. State the shared geometry, state, reference convention, wall treatment, spanwise resolution, separated-zone mesh, and output contract.

For the transition branch, report the facility turbulence input, converted N-critical value, transition onset, Cf, Cp, CL, and CD. For DDES, report shielding behaviour, three-dimensional resolved structures, time-step sensitivity, discarded transient, averaging window, and confidence interval for mean loads. Do not rank the methods from one instantaneous field or from cost alone.
