# Expected report structure

Report the shared state and mesh first, followed by the turbulence closure and freestream specification used in each Case. Compare separation and reattachment locations, wake velocity deficit, base pressure, CD, wall shear, y+, residuals, and monitor stability on common scales.

Describe the SA-to-SST spread as model-form sensitivity. A steady RANS result does not resolve vortex shedding, and agreement between two closures is not validation; include experimental or higher-fidelity reference data before making a design choice.
