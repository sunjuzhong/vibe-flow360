# T08 — Automotive wind tunnel and road-relative motion

T08 provides its own lightweight car geometry and creates stationary-road and
moving-ground Case Drafts. It teaches analytic wind-tunnel sizing, floor-model
selection, belt geometry, wheel rolling kinematics, wake refinement, and the
evidence required before comparing automotive forces. No cloud computation is
submitted automatically.

```bash
python3 tutorials/T08-automotive-wind-tunnel/build_simulation.py --check
make tutorials-validate
```
