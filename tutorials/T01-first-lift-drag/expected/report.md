# T01 review report template

## Decision

Do not report a design conclusion until both Cases satisfy the required mesh,
residual, and force-stability checks in `evidence.yaml`.

## Baseline: 0°

- Record the final CL and CD with the averaging window used.
- Attach residual and force histories.
- Attach Cp, Cf, yPlus, and CfVec views with camera and range provenance.
- Record any required evidence criterion that failed.

## Variant: 5°

- Repeat the same checks and plotting ranges.
- Compare the CL and CD changes with the baseline.
- Inspect upper-surface Cp and yPlus before interpreting the force change.

## Limitations

This template intentionally contains no fabricated coefficient values. A report
becomes engineering evidence only after the run IDs, result artifact hashes,
convergence assessment, and failed criteria are recorded.
