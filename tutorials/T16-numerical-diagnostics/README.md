# T16 · Numerical diagnostics and staged stabilization

This Web-first tutorial teaches how to classify a difficult steady CFD case before changing numerical controls. It supplies a finite-span loaded vane, a conservative recovery Draft, a second-order accuracy Draft, and a separate steady Krylov/SLAU2 evaluation Draft. The artifacts configure Drafts only; they do not claim computed results or submit solver runs.

Rebuild with `python3 tutorials/T16-numerical-diagnostics/build_simulation.py` and verify with `make tutorials-test`.
