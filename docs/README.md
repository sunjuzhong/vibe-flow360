# Vibe Flow360 documentation

Public documentation is written in English under [`en/`](en/index.md) and in
Simplified Chinese under [`zh-CN/`](zh-CN/index.md). English is the source
language. Both trees use the same paths so the language can change without
changing the subject.

Existing product and UX documents in this directory describe internal design
decisions. The `en/` and `zh-CN/` trees describe the product as it works today.
