# Ten-minute team demo

This demo uses existing resources and stops before remote submission.

## 0:00–1:30 — Set the context

“Flow360 remains our cloud solver and source of truth. Vibe Flow360 is a local,
customizable Web workspace built on its CLI. It gives us a place to add AI,
review rules, and team-specific workflows without maintaining a Python script
for every interaction.”

Show the local URL and the Flow360 connection indicator.

## 1:30–3:00 — Open cloud resources locally

Select a Folder and open a Project. Show the cached-first load, resource tree,
and one Geometry or mesh workspace. Explain that initial synchronization is
metadata-only and visualization assets are fetched when opened.

## 3:00–5:30 — Ask an engineering question

Open **Ask AI** in Resource scope. Ask for a plan to the next simulation stage.
Show a clarification request if one is returned, then open the proposed plan.

Point out the assumptions, parameter provenance, stage selection, and command
preview.

## 5:30–7:30 — Review instead of trusting blindly

Open the parameter diff and schema-driven editor. Run preflight. Explain that an
AI patch remains visible and that only the latest saved, validated revision can
be approved.

Stop at the remote submission confirmation. Do not start paid work during the
introductory demo.

## 7:30–9:00 — Inspect and compare results

Open an existing Case with results. Show convergence or a result table, then
open **Compare** and select a baseline and candidate. Ask AI what changed and
highlight any coupled variables it identifies.

## 9:00–10:00 — Close with the boundary

“The advantage is not a new solver. It is a local engineering layer we can
adapt: Flow360 performs the cloud computation, while Vibe Flow360 organizes the
context, review, AI assistance, and local reuse. It is still a prototype, so we
start with guided tutorials and reviewed pilot work.”

Invite the team to open `/tutorials` and begin with T01.
