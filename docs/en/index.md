# Vibe Flow360 documentation

Vibe Flow360 is a local Web workspace for planning, reviewing, running, and
understanding Flow360 CFD simulations. It uses the installed Flow360 CLI for
cloud operations while keeping the interaction, local mirror, review state, and
AI sessions on your machine.
