# Vibe Flow360 文档

Vibe Flow360 是用于规划、审查、运行和理解 Flow360 CFD 仿真的本地 Web 工作台。
它通过已安装的 Flow360 CLI 操作云端资源，同时把交互、本地镜像、审查状态和 AI 会话
保留在用户自己的电脑上。
