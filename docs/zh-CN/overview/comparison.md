# 使用 Flow360 的三种方式

Flow360 Python、Flow360 云端界面和 Vibe Flow360 面向不同的工作方式。Vibe Flow360
是对前两者的补充，不替代 Flow360 服务或 Python API。

| | Flow360 Python | Flow360 云端界面 | Vibe Flow360 |
|---|---|---|---|
| 主要交互方式 | Python 代码和 Notebook | Flow360 托管的 Web 界面 | 本地运行的 Web 工作台 |
| 更适合 | 可编程、可复用的自动化 | 标准的交互式云端工作流 | 团队定制和 AI 辅助工作流 |
| 扩展方式 | 编写并维护 Python | 使用云端产品提供的功能 | 修改本地服务和前端 |
| 云端访问 | Flow360 Python API | 云端界面直接访问 | 已安装的 Flow360 CLI |
| 本地状态 | 由脚本作者决定保存哪些文件 | 浏览器和云端应用状态 | Project 镜像、计划、会话和已选资源 |
| AI 工作流 | 由脚本作者自行建设 | 取决于云端产品能力 | 感知 Project、Resource 和 Draft 的助手 |
| 执行控制 | 由应用代码决定 | 由云端产品控制 | preflight、可见 diff、批准和再次确认 |

## 适合选择 Flow360 Python 的情况

需要直接的编程控制、可复用代码库、批处理脚本或 Notebook 工程流程，并且团队愿意维护
Python 代码。

## 适合选择云端界面的情况

希望直接使用 Flow360 的标准体验，不想运行本地应用，也不需要维护定制工作流。

## 适合选择 Vibe Flow360 的情况

希望使用本地浏览器工作台、AI 辅助审查、本地资源镜像，或者希望团队可以按照自己的
流程修改工作台。

三种方式可以同时使用。通过 Python 或云端界面创建的 Project，在同步到所连接的
Flow360 账号后，也可以由 Vibe Flow360 打开。
