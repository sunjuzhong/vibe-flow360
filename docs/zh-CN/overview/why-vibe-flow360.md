# 为什么使用 Vibe Flow360

Flow360 提供求解器、云端资源、Python API、CLI 和云端用户界面。Vibe Flow360 在这些
能力之上增加了一个本地工程工作台。

## 面向云端仿真的本地工作台

应用在用户电脑上运行 Go 服务，并在浏览器中提供 React 界面。它通过 CLI 读取 Flow360
Folder 和 Project，维护轻量的本地 Project 镜像，并在用户打开可视化时下载所需资源。

这种方式让团队可以控制周边工作流，而不必重新实现 Flow360。团队可以逐步加入自己的
组织规则、审查方法、可视化和内部集成，求解器与权威远程资源仍然保留在 Flow360 Cloud。

## 融入工程闭环的 AI

Ask AI 可以使用 Project、Resource 或 Draft 上下文。它能够澄清工程需求、准备计划、
提出参数补丁、协助诊断 preflight 或执行失败，并解释已有结果。

AI 不会绕过工程控制。参数变化始终可以检查，preflight 使用已安装的 Flow360 Schema，
远程提交需要用户明确批准和确认。

## 减少重复操作，不减少工程判断

本地镜像可以在实时刷新期间先显示最近的 Project 元数据。已经打开的 Geometry 可视化
资源可以从本地复用，从而减少对相同内容的重复读取；但远程刷新、运行和结果下载仍然
依赖 Flow360 Cloud 与网络。

当团队希望获得比脚本集合更容易定制的浏览器工作流，同时又不接受未经审查的
“提示词直接运行”时，Vibe Flow360 提供了一个中间层。
