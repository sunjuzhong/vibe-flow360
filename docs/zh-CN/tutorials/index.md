# 引导式教程

启动应用后打开 `/tutorials`。当前六个教程把 CFD 原理、Flow360 对象映射、受控变量、
失败诊断和明确验收条件组合在一起。配套配置可以在不提交云端任务的情况下本地验证。

| 教程 | 工程问题 |
|---|---|
| T01 — 第一组可信升阻力结果 | 怎样让 0° 与 5° 攻角的升阻力对比可以审查？ |
| T02 — 匹配 Mach 与 Reynolds 数 | 怎样同时保持风洞工况的可压缩性和黏性相似？ |
| T03 — 曲率敏感的圆柱网格 | 曲率和边界层控制如何改变圆柱网格？ |
| T04 — 保留翼型边缘与间隙 | 哪些边缘控制可以保护前缘、尾缘和狭窄通道？ |
| T05 — 加密尾流 | 体网格加密区域应该如何沿分离流向下游延伸？ |
| T06 — 选择外部远场 | 什么时候自动远场足够，什么时候必须定义 CAD 流场域？ |

每个教程都会在创建 Flow360 Project 或 Draft 前要求确认。网格生成和 Case 执行仍受正常
审批边界控制。

在仓库根目录验证所有教程包：

```bash
make tutorials-test
```

更长的教程覆盖规划描述的是未来课程。当前 Web 教程库只包含 T01–T06。
