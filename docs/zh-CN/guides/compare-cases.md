# 比较 Case

从包含 Case 的 Project 打开 **Compare**，也可以从 `/compares` 打开已保存的对比。

## 建立对比

选择至少两个 Case，并确定基准方案和候选方案。对比工作区会保存参与者顺序和可用状态，
因此即使某个 Case 已删除或无权访问，已保存的对比仍能说明其状态。

工作区可以比较：

- SimulationParams 差异
- 已有的收敛与 KPI 摘要
- 匹配的结果文件
- 兼容的表格列和数值差异
- 已有的可视化选择

并非每个 Case 都有全部内容。缺失结果会保持缺失，不会使用合成数值填补。

## Ask AI

对比分析会把所选 Case 摘要、差异和用户问题交给配置好的 Agent。回复和服务信息会作为
一个版本保存在对比工作区中。

AI 可以指出多个变量同时变化，并建议更干净的实验；如果几何、工况、模型、网格或审查
窗口同时变化，它不能证明单一因果关系。

## 参数 Sweep

对比页面可以从基准 Case 和一组参数值准备 Sweep 请求。提交前需要审查将要生成的 Case
和潜在远程任务；Sweep 会成倍增加计算消耗。
