# AI 规划与审查

Vibe Flow360 将 AI 辅助限定在正在审查的工程对象上下文中。

## 对话范围

- **Project** 范围可以引用同一 Project 中的多个资源和 Draft。
- **Resource** 范围以当前 Geometry、网格或 Case 为主要上下文。
- **Draft** 范围可以对当前 Draft 参数提出修改建议。

会话记录用户消息、AI 回复、澄清答案、错误和建议的参数差异。

## 从需求到计划

AI 可以把工程需求转换为本地计划。计划记录来源资源、目标阶段、用户意图、参数补丁、
语义差异、验证状态和命令预览。

如果缺少会显著影响结果的信息，AI 会返回结构化澄清字段，而不是静默编造。来源标签会
区分用户提供、确定性推导、推断和默认值。

## 编辑 Draft 参数

Draft 参数支持两种编辑方式：

- **Form** 使用从 Flow360 得到的 Schema，包括嵌套对象、联合类型、单位量、表达式和
  实体分配。
- **JSON** 显示完整 SimulationParams 对象。

编辑器会保留自己不负责的 Flow360 私有或未知值。AI 修改采用 merge patch，并以叶节点
级别显示修改前后的差异。

## Preflight 与批准

Preflight 通过已安装的 Flow360 Python Schema 验证候选参数。只有最新保存并验证通过的
版本可以进入审查和执行。

批准计划会冻结该版本。AI 不能替用户批准，批准也不会静默提交；远程执行还需要用户再次
确认。
