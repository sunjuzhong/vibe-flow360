# 运行监控与结果

## 提交

批准后的计划可以针对所选目标阶段调用 `flow360 draft run`。确认提交与批准计划相互独立，
因为这条命令可能启动付费云端计算。

应用会保存计划、批准的版本、已提交资源 ID 和执行阶段，因此本地服务重启后仍可以检查
工作流。

## 监控与恢复

执行监控器会刷新远程状态，并显示当前阶段、是否结束以及日志是否可用。执行错误会创建
干预记录，其中包含上下文和修复方案；选中的方案在继续恢复之前仍可审查。

如果本地进程丢失了已提交操作的跟踪状态，恢复操作会使用已保存信息与 Flow360 对账，
而不是创建一个无关的新任务。

## Case 结果

Case 工作区可以显示 Flow360 返回的结果资源。当前视图包括收敛摘要、解析后的表格预览、
Surface 和 Volume 可视化对象，以及存在对应数据时的 Slice 时间序列播放。具体控件取决于
该 Case 实际包含的文件和字段。

结果表格在本地解析，用于列摘要、预览行和图表选择。Ask AI 接收的是所选结果的有界摘要
和指纹，而不是不受限制的完整文件转储。

AI 解读只能辅助审查。接受工程结论之前，仍需检查收敛性、所选时间窗口、参考量、网格
充分性和相关流场证据。
