# 当前限制

Vibe Flow360 仍是持续开发中的原型。本地工作台已经可以运行，但没有覆盖 Flow360 Python
和云端界面的全部能力。

- 权威资源状态、网格生成、求解器执行和结果获取仍然需要 Flow360 Cloud。
- 离线访问只限于已经保存在本地镜像中的内容。
- 初次同步有意排除大型 CAD、网格、体数据和 Case 结果压缩包。
- 可用的 3D 字段、结果视图、收敛摘要和播放功能取决于每个资源实际返回的文件。
- AI Create 使用受约束的声明式 CAD 操作图，不是通用 CAD 系统，也不会执行模型生成的
  Python 代码。
- 没有配置模型服务时，AI Create 不可用，内置助手会退回到支持范围内的确定性规划行为。
- AI 解读不能替代收敛、验证和因果性判断。
- 当前 Web 教程库只包含 T01–T06；覆盖规划中的其他教程 ID 属于未来工作。
- 代码库支持修改和定制，但目前没有面向第三方的成品插件系统。
- 当前没有公开基准可以量化相对于 Flow360 云端界面的带宽节省或性能提升。

正式工程决策仍需遵循 Flow360 支持的工程方法并进行独立审查。批准远程任务前，应检查
准确参数和即将创建的云端资源。
