# 十分钟团队演示脚本

本演示使用已有资源，并在远程提交之前停止。

## 0:00–1:30 — 说明定位

“Flow360 仍然是我们的云端求解器和权威数据源。Vibe Flow360 是建立在 Flow360 CLI
之上的本地可定制 Web 工作台。我们可以在这里加入 AI、审查规则和团队工作流，不必为
每次交互都维护一套 Python 脚本。”

展示本地地址和 Flow360 连接状态。

## 1:30–3:00 — 在本地打开云端资源

选择 Folder 并打开 Project。展示缓存优先加载、资源树，以及一个 Geometry 或网格工作区。
说明初次同步只读取元数据，可视化资源会在打开时获取。

## 3:00–5:30 — 提出工程问题

在 Resource 范围打开 **Ask AI**，要求规划下一个仿真阶段。如果 AI 返回澄清问题，回答
后打开建议计划。

指出假设、参数来源、阶段选择和命令预览。

## 5:30–7:30 — 展示审查，而不是盲目信任

打开参数 diff 和 Schema 驱动的编辑器，执行 preflight。说明 AI 补丁始终可见，并且只有
最新保存且验证通过的版本可以批准。

在远程提交确认处停止，不要在介绍演示中启动付费计算。

## 7:30–9:00 — 查看并比较结果

打开一个已有结果的 Case，展示收敛信息或结果表格。然后打开 **Compare**，选择基准和
候选 Case，并询问 AI 哪些内容发生了变化。特别展示 AI 指出的耦合变量。

## 9:00–10:00 — 用边界结束演示

“优势不是新增了一个求解器，而是增加了一层可以由我们定制的本地工程工作台：Flow360
负责云端计算，Vibe Flow360 负责组织上下文、审查、AI 辅助和本地复用。它目前仍是原型，
所以我们从引导教程和有审查的试点工作开始。”

邀请团队打开 `/tutorials`，从 T01 开始。
